# Cars Dealership

## Project Details

**Repository Name:** cars-dealership

**Project Name:** Full-stack Development Capstone - Cars Dealership

## Description

Cars Dealership is a full-stack web application developed using Django and React. The application allows users to browse car dealerships, filter dealers by state, view dealer details and customer reviews, register and log in, and post reviews for dealerships.

The project demonstrates full-stack application development, REST API integration, user authentication, sentiment analysis, CI/CD, and application deployment.
